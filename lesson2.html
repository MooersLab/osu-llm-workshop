Lesson 2: Basic Commands

Essential PyMOL commands for loading, viewing, and manipulating structures

← Lesson 1: The Prompt Lesson 3: Scripting Basics →

Learning Objectives

  • Load structures from files and the PDB
  • Change representations (cartoon, sticks, spheres, surface)
  • Color structures by element, chain, residue, or custom schemes
  • Navigate the scene (rotate, zoom, center, orient)
  • Select and manipulate specific atoms/residues/chains

Loading Structures

From a local file

cmd.load("structure.pdb", "my_protein")
# cmd.load(filename, object_name)

Fetching from the PDB

cmd.fetch("1ubq", "ubiquitin")        # single structure
cmd.fetch("1ubq 2ubq", "multi")       # multiple, merged
cmd.fetch("1ubq", "ubq", type="cif")  # mmCIF format

Loading trajectories

cmd.load("traj.xtc", "protein", state=0)  # state=0 appends all frames

Check Your Understanding

When you run cmd.load("file.pdb", "obj") twice with the same object name, what happens?

Answer: The second load replaces the first object. PyMOL object names must be unique — loading into an existing name overwrites it. Use different names (or cmd.delete("obj") first) to keep multiple versions.

Check Your Understanding

What's the difference between cmd.fetch("1ubq") and cmd.load("1ubq.pdb")?

Answer: fetch downloads from the PDB database by ID (requires internet). load reads a local file from disk. fetch can also specify format (cif, pdb) and handles multiple IDs.

Misconceptions: "They're identical — fetch is just an alias for load." "load can download from PDB if given an ID." "fetch only works with the open-source PyMOL."

Representations

Change how atoms are drawn:

StyleCommandBest For
Cartooncmd.cartoon("object")Secondary structure overview
Stickscmd.show("sticks", "object")Atomic detail, bonds
Spherescmd.show("spheres", "object")Space-filling, surfaces
Surfacecmd.show("surface", "object")Molecular surface, binding pockets
Linescmd.show("lines", "object")Backbone trace, minimal
Ribboncmd.ribbon("object")Simplified secondary structure

Hide representations:

cmd.hide("sticks", "object")      # hide specific representation
cmd.hide("everything", "object")  # hide all representations
cmd.disable("object")             # disable object entirely (keeps in memory)

Pro tip: Combine representations — e.g., cartoon backbone with sticks for ligand:

cmd.cartoon("protein")
cmd.show("sticks", "ligand")

Coloring

Built-in color schemes

cmd.color("red", "object")              # single color
cmd.color("blue", "chain A")             # color a selection
cmd.spectrum("b", "rainbow", "object")  # color by B-factor
cmd.spectrum("count", "rainbow", "object")  # color by atom count

Color by properties

cmd.util.cbc("object")       # color by chain (each chain different color)
cmd.util.cbs("object")       # color by secondary structure
cmd.util.cnumb("object")     # color by residue number

Custom colors


cmd.set_color("my_green", [0.2, 0.8, 0.2])  # RGB 0-1
cmd.color("my_green", "selection")

Check Your Understanding

What's the difference between cmd.color("red", "protein") and cmd.color("red", "chain A")?

Answer: The first colors the entire object "protein" red. The second uses a selection ("chain A") to color only that subset. Selections are powerful — they let you target specific atoms, residues, chains, or combinations.

Check Your Understanding

When would you use cmd.spectrum("b", "rainbow", "obj") versus cmd.util.cbc("obj")?

Answer: spectrum colors by a numeric property (here B-factor) across a gradient. cbc (color by chain) assigns a distinct color to each chain. Use spectrum for continuous data (B-factors, conservation scores); use cbc for categorical distinction (chains, domains).

Misconceptions: "spectrum only works with rainbow palette." "cbc colors by residue number." "They produce the same result on a single-chain protein."

Selections — The Power Tool

Selections let you target specific parts of a structure. Syntax: "selection_name" or inline "criteria".

Common selection criteria

CriterionSelects
"chain A"Chain A
"resi 10-20"Residues 10 through 20
"resn LYS"All lysine residues
"name CA"Alpha carbons
"elem C"Carbon atoms
"hetero"Hetatms (ligands, water, ions)
"protein"All protein atoms
"nucleic"DNA/RNA atoms

Combining selections

# Boolean operators
"chain A and resi 10-20"      # AND
"chain A or chain B"          # OR
"protein and not hetero"      # NOT
"resi 10-20 and name CA"      # CA atoms in residues 10-20

Named selections (saved for reuse)

cmd.select("active_site", "resi 10-20 and chain A")
cmd.color("yellow", "active_site")
cmd.show("sticks", "active_site")

Check Your Understanding

What does the selection "protein and not hetero and chain A" select?

Answer: All protein atoms (not heteroatoms like ligands/water) in chain A. The and combines criteria; not excludes heteroatoms.

Misconceptions: "It selects everything in chain A including water." "not only works at the beginning." "protein includes nucleic acids."

Check Your Understanding

Why create a named selection with cmd.select("active_site", "resi 10-20") instead of just using the inline selection string?

Answer: Named selections persist, can be reused across commands, appear in the GUI panel for interactive clicking, and make scripts more readable. Inline selections are re-evaluated each time.

Misconceptions: "Named selections are faster to evaluate." "Inline selections can't be used with color/show." "Named selections are saved to the session file automatically."

Scene Navigation

Programmatic camera control

cmd.center("object")           # center on object
cmd.center("selection")        # center on selection
cmd.orient("object")           # center + zoom to fit
cmd.zoom("selection", 5.0)     # zoom on selection, 5Å buffer

# Specific view
cmd.set_view([...])            # 18-element view matrix
view = cmd.get_view()          # save current view
cmd.set_view(view)             # restore view

Rotation and animation

cmd.rotate("y", 90)            # rotate 90° around Y axis
cmd.rotate("x", -30, "object") # rotate object only
cmd.mset("1 x100")             # movie: 100 frames
cmd.mplay()                    # play movie

Getting Information


# Object info
cmd.get_names("objects")       # all object names
cmd.count_atoms("selection")   # atom count
cmd.get_model("object")        # low-level model data

# Coordinates
cmd.get_coords("selection")    # Nx3 array of coordinates
cmd.get_area("selection")      # solvent accessible surface area

# Distances/angles
cmd.distance("dist_name", "sel1", "sel2")  # create distance object
cmd.get_distance("sel1", "sel2")           # just the value

# Symmetry
cmd.get_symmetry("object")     # crystal symmetry info

Cleanup Commands


cmd.delete("object")           # remove object
cmd.delete("all")              # clear everything
cmd.reinitialize()             # full reset (keeps settings)
cmd.reset()                    # reset view only

Summary

  • load/fetch bring structures in; delete removes them
  • show/hide control representations; combine for effect
  • color/spectrum/util.cbc handle coloring
  • Selections ("chain A and resi 10-20") target specific parts
  • center/orient/zoom/rotate control the camera
