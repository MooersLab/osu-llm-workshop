Lesson 1: The Prompt

Accessing and using the Python interpreter inside PyMOL

← Home Lesson 2: Basic Commands →

Learning Objectives

  • Launch PyMOL and find the Python interpreter
  • Run Python statements directly at the PyMOL prompt
  • Understand the cmd module — PyMOL's command namespace
  • Distinguish between PyMOL commands and Python code

Starting PyMOL

Launch PyMOL from your terminal:

$ pymol

This opens the PyMOL GUI with an internal command line at the bottom. The prompt looks like:

PyMOL>

This prompt accepts both PyMOL's native commands and Python code.

The Two Ways to Run Python

1. Directly at the PyMOL Prompt

Type Python statements directly. They execute immediately:

PyMOL> print("Hello from PyMOL!")
Hello from PyMOL!

2. The Python Shell (python command)

Enter a dedicated Python REPL with python (exit with Ctrl+D or exit()):

PyMOL> python
Python 3.x.x (default, ...)
Type "exit()" to return to PyMOL.
>>> import sys
>>> sys.version
'3.x.x ...'
>>> exit()
PyMOL>

Tip: For quick one-liners, stay at the PyMOL prompt. For exploration or multi-line code, use python to enter the shell.

The cmd Module — Your Gateway to PyMOL

All PyMOL functionality is exposed through the cmd module. It's automatically imported and available as cmd at the prompt.

Importing explicitly (in scripts)

from pymol import cmd

Calling PyMOL commands from Python

Every PyMOL command becomes a function on cmd:

PyMOL> cmd.help("load")
Help on function load in module pymol.cmd:
load(filename, object=None, ...)

Key insight: cmd.load(...) in Python ≡ load ... at the PyMOL prompt. They are the same command, just different syntax.

Your First Commands

Try these at the PyMOL prompt:

# Load a structure (fetch from PDB)
cmd.fetch("1ubq", "ubiquitin")

# List loaded objects
cmd.get_names()

# See the command namespace
dir(cmd)[:10]  # first 10 entries

Check Your Understanding

What is the difference between typing fetch 1ubq at the PyMOL prompt versus cmd.fetch("1ubq") in Python?

Answer: They do the same thing — both load the PDB structure 1ubq. The first uses PyMOL's native command syntax; the second calls the same command through Python's cmd module. The Python form lets you use variables, loops, conditionals, and functions — enabling automation.

Misconception: "They're completely different systems." No — cmd is just a Python wrapper around the exact same internal command engine.

Check Your Understanding

When you're at the PyMOL prompt and type python, what happens? How do you get back?

Answer: You enter a dedicated Python REPL (Read-Eval-Print Loop) where you can write multi-line Python code. Type exit() or press Ctrl+D to return to the PyMOL prompt.

Misconceptions: "The python command runs a script file." "You can't use PyMOL commands inside the Python shell." "exit() quits PyMOL entirely."

Check Your Understanding

Why do string arguments need quotes in Python (cmd.fetch("1ubq")) but not at the PyMOL prompt (fetch 1ubq)?

Answer: At the PyMOL prompt, the command parser treats unquoted words as string arguments by convention. In Python, you're writing actual Python syntax where strings must be quoted. The cmd module is a Python library — it follows Python rules.

Misconceptions: "PyMOL's native syntax is Python." "Quotes are optional in Python too." "The cmd module uses a different parser."

Getting Help

Three ways to learn what commands exist:

  • cmd.help("command_name") — detailed help for one command
  • cmd.apropos("keyword") — search commands by keyword
  • dir(cmd) — list all available functions
PyMOL> cmd.apropos("color")
color
color_by_element
color_by_hetatm
...

Common Pitfalls

Pitfall: Forgetting quotes around string arguments in Python. 
# Wrong - PyMOL native syntax (no quotes needed at prompt)
fetch 1ubq

# Right - Python syntax (quotes required)
cmd.fetch("1ubq")
Pitfall: Using PyMOL command flags as Python keyword arguments incorrectly. 
# PyMOL native
load file.pdb, myobj, discrete=1

# Python - use True/False, not 1/0
cmd.load("file.pdb", "myobj", discrete=True)

Summary

  • PyMOL's prompt accepts both native commands and Python
  • The cmd module exposes every PyMOL command as a Python function
  • Use python to enter a full Python REPL; exit() to return
  • String arguments need quotes in Python; booleans use True/False
