Why Python in PyMOL?

PyMOL is a powerful molecular visualization system. While its graphical interface handles many tasks, the real power comes from its Python API — allowing you to automate repetitive tasks, create reproducible figures, build custom analyses, and integrate with the broader scientific Python ecosystem.

Lesson 1: The Prompt

Learn how to access the Python interpreter inside PyMOL, run your first commands, and understand the PyMOL command namespace.

Lesson 2: Basic Commands

Master the essential PyMOL commands for loading structures, changing representations, coloring, and navigating scenes — all from Python.

Lesson 3: Scripting Basics

Write reusable Python scripts: functions, loops, conditionals, and how to save and run .py files from the command line or within PyMOL.

Lesson 4: Practical Examples

Put it together with real workflows: batch rendering, measurement scripts, trajectory analysis, and publication-quality figures.

Prerequisites

  • PyMOL installed (open-source or Schrödinger build)
  • Basic Python familiarity (variables, functions, imports)
  • Basic molecular biology concepts (PDB files, chains, residues, atoms)
